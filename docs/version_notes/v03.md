# QuantumBridge-Tox — CPU GNN pilot v0.3

This is a **research pilot**, not a validated toxicity predictor. It uses the QM9 public DFT table, the standardized Tox21 table created by `restore_data.py`, and PyTorch CPU. It **does not require PyTorch Geometric, GPUs, CUDA, or new DFT calculations**.

## Scientific plan

1. Clean the labeled Tox21 endpoint, excluding conflicting labels for repeated InChIKeys.
2. Fix one scaffold-grouped **train/validation/test** split. Model selection uses validation only; test is held out until all model weights are selected.
3. Remove all QM9 records whose InChIKey is duplicated anywhere in QM9, and all molecules appearing anywhere in the standardized Tox21 file (including unlabeled rows).
4. Pretrain a small 2-layer molecular message-passing GNN on QM9 to predict `mu`, `alpha`, `homo`, and `lumo` from atom/bond graphs, without 3D geometry. Use QM9 training-label standardization and 10% separate validation.
5. Train two classifiers on the **same Tox21 split**: randomly initialized GNN, and GNN with DFT-pretrained encoder and fresh classifier head. Include a Morgan fingerprint + Random Forest reference on this exact test split.
6. Compare ROC-AUC and average precision on the same held-out toxicity molecules.

**Important limitations:** QM9 has small molecules and is not representative of all Tox21 chemical structures. DFT quantities may depend on conformers and computational settings, but this 2D graph model does not include 3D geometry. Excluding repeated InChIKeys is conservative, not an exhaustive chemical audit. Acyclic compounds use the preprocessor's canonical-SMILES fallback to form scaffold groups. Split selection uses only label balance and split size, never test model performance. Results from one split and one random seed are exploratory, not evidence of robust superiority. Verify target labels and molecule identity before publication. No medical or safety claims.

## Installation (inside existing activated `.venv`)

`torch`, `numpy`, `pandas`, `scikit-learn`, and `rdkit` are already present from previous steps. Test with:

```bash
python -c 'import torch, rdkit, pandas, sklearn, numpy; print(torch.__version__, "OK")'
```

**Default CPU pilot:**

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python -u gnn_quantumbridge.py \
  --n-qm9 5000 --pretrain-epochs 6 --finetune-epochs 8 \
  --hidden 32 --batch 32 --threads 2 --task NR-AhR
```

**Faster smoke run:**

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python -u gnn_quantumbridge.py \
  --n-qm9 1000 --pretrain-epochs 2 --finetune-epochs 2 \
  --hidden 32 --batch 32 --threads 2
```

## Produced files

Output directory: `results/gnn_v03/`. Previous data and `results/*.csv` are not overwritten.

- `tox_split.csv`: exact molecule IDs, labels and train/validation/test split
- `dft_pretrained_encoder.pt`: pretrained DFT network weights
- `scratch_gnn.pt`: classifier weights for scratch GNN
- `dft_pretrained_gnn.pt`: classifier weights for pretrained GNN
- `test_predictions.csv`: probabilities from all models on the same test molecules
- `metrics.json`: performance, held-out DFT MAEs and data counts

If results do not improve, that is a valid scientific observation. Report both positive and negative findings. Before making claims, compare multiple seeds, repeated group splits, feature ablations, external data, DFT methods and computational cost.
