# QuantumBridge-Tox v0.9 — Shuffled DFT label negative control

## Purpose and interpretation

This is **development only**. It tests whether the structure/DFT-target correspondence learned during QMugs pretraining helps on Tox21 NR-AhR when the fixed QMugs matched molecules and GNN architecture are held constant. The previously frozen **1,219 molecule test remains entirely untouched**.

**Prespecified primary comparison:** `real matched DFT minus shuffled DFT` on fixed-development **PR-AUC (average precision)**. Positive means the real DFT association beats randomized labels. ROC-AUC, F1, MCC are secondary.

### What v0.9 changes

- Reuses existing **v0.8** five-run training results (models, predictions, split, QMugs selection) **without retraining them**.
- Only trains **one new variant**: `qmugs_matched_shuffled_dft`, once per existing v0.8 initialization seed.
- Keeps exactly the same 5,000 **QMugs matched** molecules and fixed 500-molecule pretraining validation subset as v0.8, plus the same Tox21 train/inner-validation/development-evaluation scaffold partition.
- **Shuffles entire DFT target rows** (`mu`, `homo`, `lumo`) jointly, rather than shuffling columns independently. This keeps the properties' distributions and cross-target relationships while breaking their molecular correspondence.
- Train and pretraining-validation **label mappings are shuffled independently** using a fixed `--shuffle-seed`, identical across **all five model seeds**. This prevents pretraining checkpoint selection from using actual DFT labels for the sham target.
- Leaves all Tox21 NR-AhR labels unchanged and selects the toxicity decision threshold using only the same inner toxicity validation fold.
- Separately records DFT pretraining metrics against (1) shuffled validation labels and (2) **real unshuffled DFT validation labels**, for clarity. These are diagnostics rather than the primary endpoint.
- Uses independent, new `--out` path, verifies v0.8 code hashes, v0.8 inputs and frozen split, and supports `--resume` to skip already-finished seeds.

**Caveats:** This experiment measures effects **conditional on one fixed development split and one shuffled-label mapping**. No evidence of statistically significant superiority follows from five seeds by itself. A single null mapping may be atypical; consider multiple independently shuffled maps after this initial run. Also, true vs shuffled targets change optimization difficulty and the meaningfulness of early stopping; this is a negative control, not proof that the DFT mechanism causally explains any difference.

## Installation

Download `QuantumBridge-Tox-v0.9.zip` to `~/Downloads`. The ZIP includes **only** three new files; none of the existing model, results or data are overwritten:

```bash
cd ~/Downloads
unzip -n QuantumBridge-Tox-v0.9.zip -d ~/Downloads
cd ~/Downloads/QuantumBridge-Tox
source .venv/bin/activate
python test_v09.py
```

The original scripts must be present in the project folder: `gnn_quantumbridge.py`, `gnn_quantumbridge_v05.py`, `gnn_quantumbridge_v07.py`, `gnn_quantumbridge_v08.py`, as well as existing v0.8 results.

The ZIP retains the `QuantumBridge-Tox/` folder prefix so `unzip -d ~/Downloads` adds files directly into `~/Downloads/QuantumBridge-Tox`.

**There is deliberately no new 500-molecule smoke run using the existing 5,000-molecule v0.8 reference** because that would break the required matched-protocol comparison. Run `python test_v09.py` for synthetic CPU pretraining, then the v0.9 real experiment on the **same 5,000-molecule v0.8 data settings**.

## Main experiment (one negative-control permutation; five initialization seeds)

```bash
cd ~/Downloads/QuantumBridge-Tox
source .venv/bin/activate
mkdir -p logs
set -o pipefail
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 \
python -u gnn_quantumbridge_v09.py \
  --from-v08 results/gnn_v08_fixed_split_5k \
  --shuffle-seed 918273 \
  --out results/gnn_v09_shuffled_fixed_split_5k \
  2>&1 | tee logs/gnn_v09_shuffled_fixed_split_5k.log
```

The v0.9 runner obtains `--seeds 42,123,2026,731,1701`, pretraining hyperparameters and QMugs selections **directly** from the previously saved v0.8 manifest. Do **not** modify code files or data from v0.8 after generating v0.8 results: v0.9 intentionally checks script SHA-256 hashes and file identities.

If execution is interrupted, repeat with the identical arguments and `--resume` (and change `tee` to `tee -a` if you wish to append). Only incomplete seeds are retrained. A seed is considered complete only when all three CSV files for that seed are present and `results_seedX.csv` has been written as the final marker.

## Results and interpretation

The output folder contains:

- `manifest.json`: code hashes, original v0.8 experiment hash, shuffle seed, fixed partition and protocol.
- `shuffled_assignments.csv`: exact QMugs target-to-graph permutations for audit; neither Tox21 identities nor labels are shuffled.
- `results_seed<seed>.csv`, `predictions_seed<seed>.csv`, `pretraining_metrics_seed<seed>.csv` for each new negative-control run.
- `summary.csv`: existing v0.8 model means copied without retraining, alongside newly trained shuffled-control means.
- `paired_controls.csv`, `paired_controls_summary.csv`: paired per-seed comparison of **real DFT vs shuffled DFT**, plus selected prior baselines.
- `pretraining_metrics_shuffled.csv`: real DFT validation diagnostics distinct from shuffled-label metrics.

To inspect:

```bash
python - <<'PY'
import pandas as pd
p='results/gnn_v09_shuffled_fixed_split_5k'
print('\n=== MODEL SUMMARY ===')
print(pd.read_csv(p+'/summary.csv')[['variant','runs','mean_pr','sd_pr','mean_roc']].round(4).to_string(index=False))
print('\n=== PAIRED PR-AUC ===')
c=pd.read_csv(p+'/paired_controls_summary.csv')
print(c[['contrast','runs','mean_delta_pr_auc','sd_delta_pr_auc','positive_runs_pr_auc']].round(4).to_string(index=False))
print('\n=== DFT SHUFFLE PRETRAINING DIAGNOSTIC ===')
d=pd.read_csv(p+'/pretraining_metrics_shuffled.csv')
print(d.groupby('target')[['shuffled_validation_r2','r2_on_true_dft']].mean().round(4).to_string())
PY
```

## After the run

Compare real DFT against shuffled DFT on the same evaluation molecules and initialization seeds, and report each seed's difference (not only averages). If shuffled DFT matches real DFT, do not attribute a gain to the physical structure–DFT relation. If real DFT wins consistently, obtain further **independent negative-control permutations** and confidence intervals before freezing a final test protocol. Existing v0.7/v0.8 model selection and earlier exploratory comparisons mean any statistical claims remain conditional and potentially optimistic.
