# QuantumBridge-Tox v0.8 — Fixed-split, repeated-initialization study

**Purpose:** Audit whether the PR-AUC improvement observed for domain-matched QMugs DFT supervision in v0.7 persists when **only the model-training seed changes**. This version is for **development evaluation only** and is not an independent held-out final test.

The original v0.3 frozen Tox21 split is loaded and verified. Its **1,219 test molecules are excluded from all training, validation, evaluation, and feature-based matching**. Do not change the original test split or evaluate against the frozen test during this experiment.

## What is fixed and what changes?

| Component | v0.8 behaviour |
|---|---|
| Tox21 development scaffold split | **Fixed once** (`--split-seed 42`), exactly the same train / inner validation / outer dev evaluation for every run seed |
| QMugs train selection | **Fixed once** (`--selection-seed 42`); matched and random sets constant across run seeds |
| QMugs validation | Fixed disjoint pool (default 500) |
| QM9 train/validation (if selected) | Fixed and disjoint, all Tox21 InChIKeys excluded |
| DFT vs RDKit matched | Exact same QMugs pretraining graph identities, different supervision |
| Training repeats | Independent model initialization, minibatch order, and Random Forest seed |
| Primary evaluation metric | **PR-AUC / average precision** predeclared before this run |
| Secondary metrics | ROC-AUC, F1 and MCC; thresholds selected using fixed **inner validation**, never outer dev eval |

The default seven variants are: `scratch`, `qm9_dft`, `qmugs_random`, `qmugs_matched`, `qmugs_rdkit`, `qmugs_matched_rdkit`, `random_forest`.

The five default model seeds are `42,123,2026,731,1701`. Because the **same evaluation molecules** are reused in each repetition, the variation is **training instability conditional on one development partition**, *not* independent generalisation uncertainty. Five positive differences are not automatically a statistically significant discovery. QM9 and QMugs use different DFT levels; QMugs DFT targets are μ, HOMO and LUMO; no GFN2 polarizability is included.

## Main CPU experiment (five initialisations, six variants)

This focuses on comparable QMugs DFT/RDKit conditions and the Random Forest and scratch baselines. QM9 can be added in a **separate fresh run**, or include it from the start using `--variants` or omit the option to run all seven models. Because this is a fixed-split protocol, its numbers are **not directly comparable** with v0.7 mean scores across *different* development splits.

```bash
mkdir -p logs
set -o pipefail
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 \
python -u gnn_quantumbridge_v08.py \
  --seeds 42,123,2026,731,1701 --split-seed 42 --selection-seed 42 \
  --variants scratch,qmugs_random,qmugs_matched,qmugs_rdkit,qmugs_matched_rdkit,random_forest \
  --n-pretrain 5000 --qm9-val-n 500 --qmugs-val-n 500 \
  --pretrain-epochs 8 --finetune-epochs 12 --patience 4 \
  --hidden 32 --batch 32 --threads 2 --save-checkpoints \
  --out results/gnn_v08_fixed_split_5k \
  2>&1 | tee logs/gnn_v08_fixed_split_5k.log
```

**It can take hours on a small CPU.** For recovery after an interrupted run, rerun exactly the same command and append `--resume` before `2>&1` (with your log redirection replaced by `tee -a` if you want to append). The program checks data files, script hashes, split, settings and selected QMugs identities. It **skips fully complete seeds** and **restarts any incomplete seed** without overwriting complete seeds. Do not use `--resume` to change experiment settings, variants, or seed lists.

## Results

- `manifest.json`: input identity, code hashes, fixed split/selection hashes, methodological cautions.
- `fixed_dev_split.csv`: same molecular assignment for every run.
- `pretraining_selection.csv`, `selection_audit.csv`: fixed selected QMugs identities and their descriptors.
- `results_seed<seed>.csv`, `predictions_seed<seed>.csv`, `pretraining_metrics_seed<seed>.csv`: durable per-seed results for recovery.
- `development_results.csv`, `pretraining_metrics.csv`: consolidated model metrics and quantum/RDKit regression R²/MAE/RMSE.
- `summary.csv`: mean and standard deviation across model initialisations.
- `paired_controls.csv`: per-initialisation differences on **exactly the same evaluation identities**.
- `paired_controls_summary.csv`: mean, standard deviation, minimum/maximum and number of positive deltas for each comparison.
- `checkpoints/`: model states if `--save-checkpoints` requested. These **are not** independent final-test predictions.

## Interpretation and limitations

- **Fixed data, repeated training seeds** estimates how much score changes with model initialisation and training randomness on this one development split. A different external scaffold split may give a different conclusion.
- Earlier v0.7 bootstrap intervals often included zero. Don't claim statistical proof or report these fixed-split results as a held-out final test.
- DFT and RDKit differ not only in information content but in target dimensionality, noise, scale, task difficulty and optimisation; even matched graphs do not isolate a unique causal effect of quantum information.
- This model uses 2D graphs for some conformer-dependent DFT targets; QMugs uses one conf_00 conformer per ChEMBL entry (not necessarily lowest energy).
- A frozen prior test remains for **one predeclared final evaluation after methodology is settled**.

## Verification performed

The source was syntax-checked, deterministic scaffold partition tests passed, and a small **synthetic dataset** was run end-to-end on CPU with all seven variants. The resumable per-seed workflow was also exercised. **No actual v0.8 numerical performance on your Tox21/QMugs data has been computed here.**
