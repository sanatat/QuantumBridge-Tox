# QuantumBridge-Tox v0.5 — DFT R²/RMSE + toxicity F1/MCC

This is an **additive** update to your existing CPU-only QuantumBridge-Tox repository. It **does not overwrite** `gnn_quantumbridge.py` (v0.3), `gnn_quantumbridge_v04.py` (v0.4), any `.pt` models, QM9/Tox21 CSVs, or results from earlier runs.

## What's new

- **DFT pretraining / regression:** MAE, RMSE, and regression **R²** for every QM9 target, on the held-out QM9 *validation* molecules, after restoring the best pretraining checkpoint. This covers `mu`, `alpha`, `homo`, `lumo` for the `full` variant, `homo`/`lumo` for `orbital`, `mu`/`alpha` for `response`. The `rdkit` control reports the same regression metrics for **non-DFT descriptor labels**, separately identified as RDKit.
- **Toxicity / classification:** In addition to ROC-AUC and PR-AUC (average precision), reports **F1**, **Matthews correlation coefficient (MCC)**, TP/TN/FP/FN, and a **validation-selected threshold**. For each model, the cutoff maximizing **MCC on inner validation** is chosen from fixed candidates `0.01, 0.02, ..., 0.99` (ties: higher validation F1 then cutoff closest to 0.5). That cutoff is then applied **without changes** to the separate outer development-evaluation fold. The same procedure is applied to the Random Forest comparator.
- **Auditable outputs:** Per-target pretraining metrics and per-seed development-evaluation prediction probabilities are saved. F1 and MCC summaries, paired differences, and confusion counts are available in CSV.
- **Safety:** The previously examined v0.3 test IDs are excluded from v0.5 development evaluations, exactly as in v0.4. Existing results are not modified.

**Important:** R² above is regression goodness-of-fit for DFT predictions. It is NOT the QM9 property called `r2` (electronic spatial extent). Classical R² is not an appropriate primary measure for binary Tox21 toxicity.


### Main output files

- `pretraining_metrics.csv`: seed, variant, QM9 count, DFT/RDKit target, **MAE, RMSE, R²**, validation count and selected pretrain epoch.
- `development_results.csv`: one row per model and seed, **ROC-AUC, PR-AUC, F1, MCC, confusion counts**, validation-selected threshold, inner-val F1/MCC, and pretraining summaries for GNN variants.
- `summary.csv`: mean ± sample SD for ROC-AUC, PR-AUC, F1, MCC; SD is missing for one seed.
- `paired_deltas.csv`: differences versus scratch GNN on the same outer-development fold for all four metrics.
- `dev_predictions_seed<seed>.csv`: probability of positive toxicity in the outer-development fold for each variant, with chemical ID and true label; these must never be used to select thresholds.
- `dev_split_seed<seed>.csv`: frozen per-seed inner-train/inner-validation/outer-development assignments.
- `manifest.json`: configuration and methodological notes.

This repeats model training and may take time on a CPU. If you only want a working check, finish the smoke test and inspect its CSVs before attempting the long run.

## Interpretation and limitations

- Select the *epoch* on inner validation AP; select the *decision cutoff* on inner validation MCC; score F1/MCC on a **separate outer development fold**. Inner-validation F1/MCC are not independent performance estimates.
- Development folds overlap between seeds and are not a genuine held-out external validation set. Do not claim statistical significance from 3 seeds.
- ROC-AUC and PR-AUC are ranking metrics, **independent of the selected classification cutoff**. F1 and MCC depend on that cutoff and the endpoint prevalence.
- R² may be negative; that is not a code error. If a target has effectively constant variance, its R² is undefined and recorded as blank/`null`.
- The DFT GNN is a 2D message-passing graph model trained to predict DFT **labels**. It does not take QM9 3D geometries as input, and the original Tox21 test set has been viewed in earlier experiments; do not reuse it to tune or claim unbiased final performance.
- The Python scripts were sanity-checked with small synthetic molecules on CPU for all three modes (`multiseed`, `ablation`, `curve`). This is not a real QM9/Tox21 training result.
