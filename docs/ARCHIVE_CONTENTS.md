# Archive contents and completeness

This is a **source-code + documentation GitHub package**, not a byte-for-byte copy
of the original developer's Linux project folder.

Included:
- Original v0.1 baseline, v0.2 restore helpers, v0.3 message-passing GNN,
  v0.4–v0.9 training/experiment runners, tests and v0.7 bootstrap utility.
- Long GitHub `README.md`, version-specific notes, research report (Markdown/PDF),
  external validation protocol and pilot figures.
- Research pack scripts for local result auditing and a proposed external assay audit.
- Requirements, `.gitignore`, and README explaining dataset restoration.

Not included because those bytes are only on the user's Linux machine:
- `data/qm9.csv`, `data/tox21_clean.csv.gz`, `data/qmugs/summary.csv`,
  `data/qmugs/qmugs_v06_pool.csv.gz` or their audit JSON.
- Original `results/` (including `gnn_v03_5k/tox_split.csv`, run CSVs,
  manifests, model checkpoints) and run logs.
- Virtual environment, caches or local system configuration.

**CAUTION:** The pilot metrics documented in README are transcribed from user's
completed terminal runs, not generated by a bundled results dataset. External
validation remains unperformed. Do not portray the source package as an independently
reproduced benchmark or a complete archival snapshot of the local experiment.

If you want a literal full local backup with datasets/results/checkpoints, create
it **on your Linux machine** after reviewing size and confidentiality.
The GitHub upload should ordinarily exclude large raw datasets and checkpoint files.
